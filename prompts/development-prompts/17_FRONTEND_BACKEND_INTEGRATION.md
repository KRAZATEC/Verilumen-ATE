# Prompt 17 — Full-Stack Integration

Integrate the Next.js frontend with FastAPI without duplicating business logic.

## Requirements
- typed API contracts
- upload progress/state
- dataset session lifecycle
- cached analytics queries
- filter/query synchronization
- graceful backend errors
- retry only where safe
- cancellation for long requests where feasible
- consistent formatting of numeric values and units

## End-to-end workflow
Demonstrate a new user journey from CSV upload to dashboard, investigation, AI analysis and prediction.

## Robustness
If a backend capability is unavailable, the UI must show a meaningful state rather than fake content.

## Tests
Add integration tests for critical user journeys and contract mismatches.
